Como usar este guia

Este não é um livro para ler uma vez e esquecer. Ele foi montado como um jogo: cada capítulo é uma fase, cada fase tem missões, e cada missão dá XP.

Você pode ler na ordem ou pular direto para o jogo que mais gosta. Só não pule a Fase 10 (o Método do Explorador): ela vale para qualquer jogo.

Como funciona o XP

Cada missão mostra quanto XP vale. Quando completar uma, marque a caixinha e some os pontos. No fim do guia você descobre seu nível de explorador.

1Novato CuriosoComeçou a jornada0 XP
2ExploradorJá sabe onde procurar150 XP
3Caçador de SegredosEncontra o que os outros não veem400 XP
4Mestre dos Easter EggsOs amigos pedem dicas para você800 XP
5Lenda dos GamesCompletou o Desafio Final1.200 XP

Lendo no celular? Use a ferramenta de anotação do seu leitor de PDF para marcar as caixinhas e escrever nos campos. As páginas de missão e o diário também podem ser impressas.
