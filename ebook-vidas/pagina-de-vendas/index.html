Perguntas frequentes

Como recebo o e-book?

Depois que o pagamento é aprovado, a Hotmart envia o acesso para o seu e-mail. O livro é um PDF que você pode baixar e guardar.

Dá para ler no celular?

Sim. O livro foi diagramado em formato de bolso, pensado para ler no celular.

Preciso ter o jogo para ler?

Não. As histórias são completas e divertidas mesmo para quem nunca jogou um simulador de vida. Mas, se você joga, vai querer testar os desafios.

As histórias são reais?

Não. São histórias de ficção, inventadas no estilo dos simuladores de vida. Nomes e acontecimentos são imaginários.

É um produto oficial do BitLife?

Não. É uma obra independente, inspirada no gênero dos simuladores de vida, sem ligação com a desenvolvedora do jogo.
